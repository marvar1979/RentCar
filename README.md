# RentCar
LINK:https://marvar1979.github.io/RentCar/

RentCar Professional es una plataforma web orientada a la gestión integral de un servicio de alquiler de vehículos. Permite centralizar las operaciones relacionadas con clientes, reservas, contratos, flota, pagos, mantenimiento y recursos humanos desde una misma interfaz.

Esta edición está construida exclusivamente con:

HTML5
CSS3
JavaScript ES6+
JSON
localStorage / sessionStorage
Web Storage

No requiere Node.js, base de datos ni servidor para ejecutarse localmente.

Enfoque funcional

RentCar Professional está pensado para administrar el flujo completo de una empresa de alquiler de vehículos, desde el registro del cliente y la reserva hasta la entrega, devolución, inspección, pago y cierre del contrato.

El sistema también incorpora gestión administrativa, control de flota, mantenimiento, finanzas, recursos humanos, usuarios, roles y auditoría.
