RentCar Professional — Manual

Proyecto ejecutable directamente desde index.html. No utiliza frameworks, servidores, bases de datos externas ni CDN: solamente HTML, CSS, JavaScript y JSON.

Inicio

  1. Abre index.html.
  2. Consulta credenciales.html para elegir un rol.
  3. Inicia sesión. El menú se genera según permisos.

Módulos

Operaciones
Clientes, reservas, contratos, entrega, extensión y devolución.
Flota
Vehículos, categorías, inspecciones, daños, mantenimientos y transferencias.
Finanzas
Pagos, comprobantes, caja y reportes financieros.
RRHH
Empleados, asistencia, vacaciones, contratos laborales y evaluaciones.
Administración
Usuarios, roles, permisos, parámetros y auditoría.
Documentos
Adjuntos locales vinculados a entidades.

Reglas implementadas

  • Control de colisiones de reservas por vehículo y rango de fechas.
  • Validación de licencia, seguro e inspección técnica.
  • Reserva → contrato → devolución → inspección → cierre.
  • Bloqueo de vehículo por mantenimiento y transferencia.
  • Cierre de contrato solo cuando el saldo está cubierto.
  • RBAC: los módulos y operaciones dependen del rol.
  • Auditoría de altas, cambios, eliminaciones y flujos.
  • Bloqueo temporal tras 5 intentos fallidos de login.

Persistencia

La base local se guarda en localStorage. En el menú de usuario puedes exportar/importar un respaldo JSON o restaurar los datos iniciales.

Límite técnico

Una solución únicamente HTML/CSS/JS/JSON no puede ocultar secretos ni proteger datos frente a una persona con acceso al navegador y al código fuente. Este proyecto reproduce la lógica, roles y flujos de una aplicación empresarial, pero para múltiples usuarios reales se requiere backend y base de datos de servidor.
